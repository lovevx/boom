# EXPERIENCE.md —— 体验目标

> 玩家应该感觉到什么，以及我们怎么知道做到了。给"调味道"用，AI 最容易跑偏的地方。

## 核心体验关键词

1. **干脆** —— 放置即响应，爆炸即摧毁，不拖泥带水
2. **爽** —— 震屏 + 飞散 + 碎裂，破坏反馈层层叠加
3. **变强感** —— 升级后立刻能感受到范围/伤害/金币变化
4. **省力/挂机变强** —— 自动化炮台逐步替代手动点击，越玩越省力；自动化效率（更多/更快/更强炮台、更高收益）持续提升

## 关键时刻

- **First 30s**：玩家能在 30 秒内理解「锤砸 → 赚金币 → 升级 → 解锁炮台 → 自动轰炸 → 炸更猛」，并在首次升级后明显感受到变强。这是 MVP 验证目标。
- **首炸**：第一颗炸弹爆炸必须同时给出震屏 + 方块飞散 + 碎裂，建立"破坏爽感"的第一印象。
- **升级后首炸**：升级爆炸范围/伤害后，下一次爆炸要让玩家主动说出"变强了"。

## 反例 / 已否决的体验方向

- ❌ **不要做成烟花秀**：如果只有特效、没有实质破坏反馈（方块不飞散），体验就是"放烟花"，被否决。
- ❌ **不要一上来就给满**：自动化应有清晰解锁节奏（炮台按序部署、费用递增、伤害/范围/速率分路升级），一上来炮台全开或无解锁门槛会让升级失去意义、没有"变强感"。
- ❌ **不要一炸全没**：方块无血量、炸一下就全塌，破坏就没有层次感和"再来一发"的欲望。
- ❌ **不要升级无感**：金币只累加、升级无可见影响，循环无法闭合，属于核心禁区。
