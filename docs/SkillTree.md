# 技能树系统（2026-10-09）

技能树保留现有四向布局、14 个节点和等级上限。参数见 [Numeric_Balance.md](Numeric_Balance.md)，代码唯一来源为 `UpgradeManager.RUN_VALUES / RUN_COSTS` 与各炮台、机制升级表。

## 分支定位

- 锤子：伤害压缩击破次数，速度压缩间隔，范围改善点击容错并逐步覆盖相邻方块。暴击在第一次有效转生后加入。
- 金币：倍率与每块基础金币形成不同投资回报，基础金币改为每级 +1，价格独立。
- 炮台：数量提高并行输出，速率提高单台频率，伤害克服材质 HP，范围扩大覆盖。数量不再附送冷却缩短。
- 建筑：下落速度缩短补层等待，是辅助吞吐分支。

## 前置关系

炮台数量 Lv.1 → 伤害、范围、速率。

锤伤 Lv.2 + 转生 ≥1 → 暴击率；暴击率 Lv.1 + 转生 ≥1 → 暴击伤害。

炮弹伤害 Lv.2 + 转生 ≥2 → 连锁；炮弹范围 Lv.2 + 转生 ≥3 → 散射。

## 状态与购买

`get_node_state()` 返回 locked / available / lit / maxed、等级与锁定原因。`purchase_node()` 在管理器内统一校验前置、满级、金币、扣款与升级；锁定/满级/未知/余额不足均不消费金币。满级费用统一返回 -1。

悬停提示显示当前实际效果、下一级实际效果、等级、费用与锁定原因；购买后立即刷新。伤害与攻速显示实际伤害/间隔而非只显示内部倍率。前置连线与实际判定一致。

节点 ID 与存档等级键不变；读档使用新表重建效果，不需要删档。旧等级保留，新的价格只作用于后续购买。
