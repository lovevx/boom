# MVP 范围声明

**MVP 只做**：锤子挥砸破坏建筑方块、方块破碎成碎屑飞溅、金币破碎产出、金币 UI、基础升级（解锁炮台 / 范围 / 伤害 / 金币倍率）、震屏、重新开始。（破坏反馈统一做**破碎/粉碎效果**，不做掉落）

**MVP 不做**：多种炸弹、多种建筑、连锁爆炸、离线收益、慢动作、单局存档、设置、成就、复杂粒子特效、关卡推进、转生系统（永久 meta 进度，属 MVP 后 P2 内容，见 Reincarnation.md）。（注：自动炮台轰炸属核心玩法，已在 MVP 范围内；"自动化"方向见 Core_Loop 的成长分阶）

**MVP 验证目标**：玩家能否在 30 秒内理解"锤子砸 → 砸坏房子 → 金币破碎产出 → 升级解锁炮台 → 自动轰炸炸更猛"的成长路径，并在解锁炮台后明显感受到破坏方式升级的快感。

**重新开始（reset）范围**：增加顶部"重新开始"按钮 + 二次确认框，确认后一次性重置金币归零、技能树/升级全部清零、楼体完整重建、清理场上残留弹体/碎屑/伤害数字并隐藏全部炮台，让玩家回到"只有锤子 + 空金币 + 满楼"的初始状态快速回测；未点确认不执行任何重置。
