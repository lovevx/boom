# SPEC.md —— 规格约束

> 写给 AI 看的硬性规格。一切"AI 不能擅自改"的东西都放在这里。

## One-liner

一款 2D 休闲破坏挂机游戏：锤子砸楼 → 赚金币 → 升级强化锤子与经济 → 解锁炸弹炮台自动轰炸 → 炸更猛、赚更多、越玩越省力。

## 核心循环

玩家一开始用锤子点击挥砸建筑方块，方块破碎成碎屑飞溅并产出金币；用金币在升级面板强化锤子（速度/伤害/范围）、经济（金币倍率）等；当通过升级项解锁炸弹炮台后，炮台会自动朝建筑持续发射炸弹，实现更大范围破坏、炸出更多金币，循环往复。自动化从炸弹派生，锤子随发展逐渐退居辅助。

## 关键参数 / 数值边界

| 参数 | 边界 | 说明 |
| --- | --- | --- |
| 同时存在的炸弹数 | 1~5，当前默认 5（解锁「炸弹」升级项后才可用） | 防止无脑堆叠，留出策略取舍空间 |
| 引信时间 fuse_time | 0.8~2.0 秒，默认 1.5 | 太短没操作感，太长拖节奏 |
| 爆炸半径 explosion_radius | 80~300，默认 150 | 影响破坏规模与策略 |
| 爆炸伤害 explosion_damage | 3~15，基础默认 3（随"从1起步"缩档） | 配合方块血量调整"炸几下碎" |
| 方块血量 hp | 3~16（挡 0 窗 3 / 墙 5 / 楼板 7，随挡位升到墙 12 / 窗 8 / 楼板 16；"从1起步"缩档） | 决定建筑的抗炸程度 |
| 点击间隔（点击CD） | 基础 0.5s（`Hammer.attack_speed=2.0`），下限 0.30s（`MIN_COOLDOWN`） | 需求"节奏CD"甜点区；CD不下于下限，防手速碾压摧毁挡位分层 |
| 冲击力 explosion_impulse | 200~900，默认 500 | 太小飞散不明显，太大飞出屏幕 |
| 方块尺寸 | 40x40；楼体为无限层塔，同屏约 15 层（~165 块，楼板隔层固定出现、墙面层随机开窗），任意层清空后其上方楼层塌落补位、楼顶补出新层 | 保持白盒性能与观感，砸掉一层掉一层 |
| 碎块尺寸 | 5~9，每方块碎裂 2~3 个 | 碎裂感与性能的平衡 |
| 场景切场碎块 | cols=10, rows=7；重力 2400；速度上限 1600；起步爆散 60；角速度 ±120°/s；起步延迟 ≤0.25s；切场延迟 0.25s；生成弹跳 0.6/0.12s；震屏半径 10、时长 0.25s | 切场过场：旧屏切成矩形碎块下落露出新场景；生成瞬间弹跳+全屏震屏增强破碎手感 |
| 分辨率 | 1920x1080 | 主场景固定，边界清理按此写死 |
| 平台 / 性能 | Godot 4.7，GL Compatibility，桌面端优先 | 物理用 Jolt |
| 转生点收益 K（RP_GAIN_K） | 1.0 | 转生点缩放系数，越大每次转生得点越多 |
| 转生点基准（RP_GAIN_BASE） | 1000；K=1；单局上限 8 RP | 达到当轮门槛后按平方根公式结算 |
| `run_gold_targets` | 默认 [4000, 9000, 30000]；长度 3，正数且递增 | 当前转生次数索引，3 次以后沿用末项；统一驱动结算与提示 |
| `DemoProgress.finale_gold` | 默认 1000000，必须 >0 | 第三次转生后本轮拆楼产出目标；不使用余额 |
| `DemoProgress.required_scatter_volleys` | 默认 10，必须 ≥1 | 最终轮实际多发散射轮数；一轮只计一次 |

## 升级项（升级面板，购买后实时生效）

新增机制的控制参数集中在 `UpgradeManager` 顶部导出项，永久专精增量集中在 `ReincarnationManager.specialization_steps`。节点费用和等级效果继续采用最新版本的集中表，见 [Demo_Expansion.md](Demo_Expansion.md)。以下为本次测试使用的默认值，修改后需同步文档并重跑成长检查。

| 参数 | 默认 / 边界 | 用途 |

| `specialization_steps` | 容错 0.4 秒 / 重锤 20 px / 残血阈值 0.05 / 回收 1 金币 / 合同 0.25 / 采购 0.05 / 保底 0.05 / 余震范围 0.10 / 重炮周期减 1 | 每级永久专精增量；与同名节点 ID 对应 |

首次转生门槛为产出 4000，后续依次为 9000 / 30000；RP 基准 1000、每局上限 8。炮弹基础伤害表为 10 / 14 / 19 / 25 / 34 / 46，首炮费用 40，首级炮伤 / 范围费用 80 / 100。沿用 12 列 ×30 层与单局可购买 4 台炮台。上文未更新的旧参数及下方旧版基础升级表仅作历史记录，以最新数值文档与管理器集中表为准。

| 升级项 | 初始 | 每级提升 | 上限 | 说明 |
| --- | --- | --- | --- | --- |
| 锤子速度 | ×1.0 | +0.4 | 3 级 | 攻速倍率（百分比） |
| 锤子伤害 | ×1.0 | +0.3 | 3 级 | 锤击 / 爆炸伤害倍率（百分比） |
| 锤子范围 | 0px | +7px | 5 级 | 命中半径，0=仅命中点击处单个方块（绝对值） |
| 金币倍率 | ×1.0 | +0.5 | 5 级 | 产出金币放大 |
| 基础金币 | 0 | +5 | 5 级 | 单块击破的基础金币加值（绝对值，先加后乘倍率） |
| 建筑下落速度 | ×1.0 | +0.5 | 3 级 | 塌落下坠提速（百分比） |
| 解锁炮台（发射器数量） | 锁定 | 单局仅 Lv.0→1 | 5 档 | 升至 Lv.1 部署第一台自动炮台；Lv.2/3/4 数量由转生系统永久解锁，见 Reincarnation.md |

> 上限口径：基础数值/绝对值 → 5 级；百分比/倍率 → 3 级。
> **「全自动锤」不在单局升级项**，仅由转生永久树「初始熟练」提供（见 Reincarnation.md）。

> 当前已实装上表全部项。「解锁炮台」为核心的**机制型升级项**：未解锁（发射器数量 Lv.0）时无任何炮台在场，纯锤子玩法；解锁后炮台自动朝建筑持续发射（自动挂机），伤害/范围/速率由独立升级项驱动。

## 明确不做的事（Non-goals）

- 不做多种炸弹、多种建筑、连锁爆炸、关卡推进
- 不做慢动作、特写、复杂粒子特效
- 不做单局存档（单局进度不持久化）；转生永久进度（转生点/永久节点/转生次数）需本地存档，见 Reincarnation.md
- 不做设置界面、成就/统计、皮肤/美术替换
- 不做音效（当前 MVP 阶段）
- 不做除"鼠标点击"以外的其他操作方式（挥锤为点击；炮台/全自动锤为自动触发的例外）
- 不做手机适配与性能优化

## 2026-10-13 表现优化参数

本轮按表现优化需求补充轻量绘制效果，沿用现有像素素材与粒子预算。以下只影响画面；伤害、金币、冷却、弹道与楼体槽位保持现有规则。配置位于 `PresentationProfile.gd`，资源为 `assets/presentation/profile.tres`。

| 参数 | 默认 / 边界 | 用途 |
| --- | --- | --- |
| `blast_seconds` | 0.55 秒，必须 >0 | 爆炸序列结束后保留短暂压力环与火星 |
| `blast_sparks` | 10，建议 0～16 | 每次爆炸直接绘制的火星数；低特效关闭 |
| `impact_seconds` | 0.24 秒，必须 >0 | 锤击弧线、火花与定向炮口闪光的生命周期 |
| `trail_points` | 12，建议 2～16 | 单颗炮弹世界坐标尾迹点数上限；低特效缩至 5 点 |
| `trail_spacing` | 5 px，必须 >0 | 尾迹采样最小间距 |
| `dust_drift` | 28 px，建议 0～40 | 扬尘上升距离，兼有横向扩散与淡出 |

锤击和炮口效果共用 `hit_limit=48`；爆炸共用 `blast_limit=8`；粉尘共用 `dust_limit=12`。低特效沿用预算缩减。减少动态效果时隐藏尾迹、冲击环、飞散火花，使用小范围命中提示，降低碎屑速度，并关闭粉尘位移动画。所有新增效果随游戏暂停，并归入 `in_game_entity` 以在重开时清理。碎屑从各自被毁方块位置发射，沿远离攻击来源的方向散开。
