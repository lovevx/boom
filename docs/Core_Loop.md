# 核心循环（Core Loop）

## 一、核心循环描述

玩家一开始用锤子砸建筑方块，使其破碎成碎屑飞溅并产出金币；用金币升级变强，逐步解锁更强的破坏方式（最终解锁炸弹炮台）。解锁炮台后它会自动朝建筑持续轰炸，实现更大范围的破坏，砸/炸出更多金币，循环往复。

## 二、循环图

```
用锤子砸 → 砸毁方块 → 碎屑飞溅 → 产出金币
    ↑                                        ↓
    └──── 升级解锁炮台、强化破坏 ←──── 金币 UI / 升级面板
        └→ 炮台自动轰炸 → 抛射爆炸（更大范围破坏）
```

## 三、破坏方式的成长分阶

破坏方式不是一成不变的，而是从"手动操作"逐步滑向"自动化"，锤子的作用随升级逐渐弱化：

| 阶段 | 破坏方式 | 玩家行为 | 锤子的角色 |
| --- | --- | --- | --- |
| 前期 | 手动用锤子砸 | 高频手动点击破坏 | 核心，唯一破坏手段 |
| 中期 | 解锁炸弹炮台 | 解锁后炮台自动朝建筑轰炸，局部范围破坏 | 仍有作用，但开始退居辅助 |
| 后期 | 解锁自动化升级 | 扩充自动化（更多/更快/更强炮台、自动收集等），无需手动操作 | 弱化为过渡工具，几乎不再用 |

设计原则：升级的长期价值 = 把"重复手动操作"替换成"更强的自动化机制"，让玩家从"越砸越累"走向"越玩越省力"，这才是增量后期的持续爽点。自动化**从炸弹派生**（炮台自动轰炸、自动收集等），锤子不参与后期自动化，仅作为前中期的过渡工具。

## 四、动词与关键功能对照

| 循环中的动词 | 对应关键功能 |
| --- | --- |
| 锤子砸 | 初始破坏工具：锤子挥砸（P0），方块血量与多次打击（P1） |
| 解锁炮台 | 炮台作为升级项解锁（P0/P1）、升级面板（P0） |
| 轰炸 | 自动炮台（BombLauncher）发射抛射炸弹（P1，解锁后在场自动开火） |
| 爆炸 | 抛射炸弹爆炸（BombProjectile，P1）、爆炸震屏（P1） |
| 砸毁/炸毁 | 可破坏的建筑方块（P0）、方块破碎成碎屑飞溅（P0）、连锁倒塌效果（P1） |
| 产出 | 方块破碎粉碎特效（P0）、金币破碎产出（P0） |
| 查看 | 金币计数 UI（P0）、基础 UI：金币、升级按钮（P0） |
| 升级 | 升级面板（P0）、升级项：解锁炮台/锤子强化/爆炸范围/爆炸伤害/金币倍率（P1） |
| 再来一发 | 重新开始/下一关按钮（P1） |
