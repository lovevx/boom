# 优先级 Backlog

## 优先级定义

| 优先级 | 含义 |
| --- | --- |
| P0 | 核心玩法必需，缺失则循环断裂，MVP 必须完成 |
| P1 | 显著提升反馈与爽感，强烈建议 MVP 内完成 |
| P2 | 内容扩展与打磨，MVP 之后优先做 |
| P3 | 锦上添花，不影响核心玩法判断，视情况实现 |

## 功能优先级表

| 功能名 | 优先级 | 一句话理由 |
| --- | --- | --- |
| 锤子挥砸（初始工具） | P0 | 初始破坏方式，没有锤子就没有最基础的破坏操作 |
| 可破坏的建筑方块 | P0 | 没有可破坏目标，砸了也白砸 |
| 方块受力飞散 | P0 | 飞散是破坏爽感的基础，不飞散就是假破坏 |
| 破坏震屏 | P0 | 震屏是破坏反馈最直观的部分，缺了砸像敲空气 |
| 破碎粉碎特效 | P0 | 方块粉碎成碎屑飞溅，让破坏有"碎裂感"，是视觉爽点的核心（不做掉落，统一做成破碎效果） |
| 金币破碎产出 | P0 | 房间里没有金币产出，破坏就没有收益反馈 |
| 金币计数 UI | P0 | 没有 UI 玩家不知道赚了多少，循环断裂 |
| 升级面板 | P0 | 没有升级，金币就只是数字，循环无法闭合 |
| 基础 UI：金币、升级按钮 | P0 | 没有 UI 玩家无法理解状态和操作 |
| 解锁炮台（升级项） | P1 | 炸弹炮台是升级解锁的进阶破坏方式，是"变强"的核心呈现 |
| 自动炮台在场轰炸 | P1 | 解锁后炮台自动朝建筑发射炸弹，是进阶破坏的载体 |
| 抛射炸弹爆炸 | P1 | 解锁炮台后抛射炸弹的爆炸反馈，让进阶破坏成立 |
| 爆炸震屏 | P1 | 解锁炮台后的更强反馈，与锤子震屏共同构成破坏爽感 |
| 爆炸范围可视化 | P2 | 让玩家一眼看出轰炸威力有多大；随自动化方向发展，该反馈的意义明显下降 |
| 升级项：锤子强化 | P1 | 让升级对最基础的破坏效率也有影响 |
| 方块血量与多次打击 | P1 | 让破坏有层次感，而不是炸一下就全没 |
| 连锁倒塌效果 | P1 | 承重方块被炸后带动周围方块倒塌，是核心爽点 |
| 升级项：爆炸范围 | P1 | 最直观的变强反馈，升级后立刻能感受到 |
| 升级项：爆炸伤害 | P1 | 让升级对破坏效率有明确影响 |
| 升级项：金币倍率 | P1 | 让金币增长有加速感，驱动继续拆 |
| 自动化破坏（炮台扩增 / 自动收集） | P2 | 从炮台派生的自动机制，把手动破坏替换成自动，是后期爽点核心方向 |
| 金币自动收集 | P2 | 减少手动捡币操作，向"挂机省力"推进 |
| 全自动化 / 离线收益 | P3 | 增量游戏的后期形态，但 MVP 阶段可不做 |
| 重新开始/下一关按钮 | P1 | 试玩验证必须能快速重开或推进 |
| 多种建筑类型 | P2 | 提升重复游玩价值，但 MVP 一种够用 |
| 多种炸弹类型 | P2 | 丰富策略，但会增加复杂度 |
| 建筑血量条/耐久显示 | P2 | 让玩家知道还要炸几次，提升目标感 |
| 连锁爆炸（炸弹引爆炸弹） | P2 | 大幅提升爽感，但实现成本较高 |
| 音效：爆炸、碎裂、金币、放置 | P2 | 明显提升反馈感，但不影响玩法成立 |
| 金币拾取动画 | P2 | 让收益更有"获得感"，属于反馈打磨 |
| 关卡推进与难度递增 | P2 | 让游戏有阶段性进展，而不是一直拆同一栋楼 |
| 慢动作/爆炸特写 | P3 | 提升爽感，但属于打磨层 |
| 粒子特效：烟尘、火花、碎片 | P3 | 提升表现力，删了不影响核心玩法 |
| 转生存档（ConfigFile） | P1 | 转生永久进度依赖本地存档，转生系统实装时必须同步做 |
| 存档/进度保存（单局） | P3 | 单局进度不持久化；正式体验需要时再做 |
| 转生系统（永久 meta 进度） | P2 | 单局爽完归零缺乏长期目标，转生提供永久加成驱动留存，见 Reincarnation.md |
| 永久技能树（三大方向） | P2 | 转生点消费出口：获取金币 / 攻击 / 炮台 |
| 炮台数量转生迁移 | P2 | 单局仅解锁第一台，Lv.2/3/4 由转生永久解锁 |
| 设置界面：音量、画质 | P3 | 完善体验，但不影响核心循环验证 |
| 成就/统计 | P3 | 增加长期目标，但属于后期内容 |
| 皮肤/主题/美术替换 | P3 | 提升包装感，但不影响玩法判断 |
