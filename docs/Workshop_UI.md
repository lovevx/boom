# 拆楼工坊 UI 风格与动态表现

这一轮把 UI 从平面色块改成带材质结构的工地机械操作台，沿用现有工程黄、钢蓝灰与青色信号灯配色。

## 视觉

- 主次按钮使用独立绘制的钢板、压铸金属九宫格皮肤，包括切角、垫层、倒角高光、螺钉、刻槽和警示条。
- 菜单、HUD、提示卡、设置、存档及转生面板共用机械边框。警示条保留固定尺寸，不随宽面板拉成大色带。
- 技能树采用工程蓝图网格与标尺分区，节点增加多层倒角和铆钉；原有节点、费用、效果和解锁条件不变。
- 原始皮肤为可编辑 SVG，位于 `assets/presentation/workshop/`。生成入口为 `tools/build_workshop_ui.py`，无需外部图片或服务。

## 动态

- 按钮悬停：高光沿倒角移动，侧边机械括号渐亮。
- 按钮按压：金属明暗和文字内边距切换，触发短暂冲击闪光；按钮本体和点击范围不缩放。
- 面板打开：20px 滑入并淡入，窗口变化时终止旧位移动画并按新窗口重新居中。
- 主菜单：按钮逐项浮现，标题轻微浮动。
- 工程面板：状态灯依次亮起，底部检修光标移动；获得金币时表盘短暂发光，保留已有数字滚动。
- 技能树：可购买节点显示动态弧光，保留升级脉冲、连线流动及购买反馈。

装饰由 `WorkshopChrome.gd` 承担，不接收鼠标输入，不修改父控件的点击矩形。装饰重绘上限为 30Hz，隐藏界面不重绘。减少动态模式停止扫描、闪光和浮动，并取消新面板的滑入与淡入。

## 验证

全部运行使用独立的 `BoomameDemoValidation` 用户数据目录，没有更改玩家设置或存档。

- UI、新手闭环、箭头避让与四种分辨率：87 项通过。
- 材质皮肤、真实悬停/按压、暂停状态动效、减少动态及场景重建：16 项通过。
- 最终运行没有脚本错误；测试退出阶段仍有 Godot CanvasItem/ObjectDB 释放警告。

`artifacts/workshop/motion.mp4` 为约 10 秒、30 FPS 的真实 Godot 录像，演示菜单、按钮、HUD、技能树、设置和转生。测试脚本注入金币以展示交互，不用于评估成长节奏。
