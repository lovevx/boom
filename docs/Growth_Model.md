# 成长模型（2026-10-09）

当前参数见 [Numeric_Balance.md](Numeric_Balance.md)。数值表是效果的唯一来源，界面描述直接查询管理器。

- 锤击伤害 =（1 + 永久基础伤害）× 单局锤伤表 ×（1 + 破坏之力）。
- 锤击间隔 = max(0.30, 0.5 /（单局锤速表 ×（1 + 疾风之势））)。
- 锤击半径 = 单局范围表 + 永久巨人之力。
- 每块金币 = round（（材质金币 + 单局基础金币 + 永久击破金币）× 单局金币倍率表 ×（1 + 金币之心））。
- 炮弹伤害 =（单局伤害表 + 永久炮塔基础伤害）×（1 + 弹药强化）；再按爆炸距离衰减。锤伤不影响炮弹。
- 爆炸半径 = 单局范围表 ×（1 + 爆裂范围）。
- 炮台冷却 = 3.4 秒 × 单局速率表；数量为独立等级，不额外缩短冷却。
- 建筑下落 = 单局下落表 ×（1 + 重力加速）。

`UpgradeManager.recalculate_stats()` 从等级重建派生属性，重复执行不会累积加成。永久购买、单局升级、重置和读档都使用同一公式。转生不是单次无限指数增长，永久节点有级数上限，单局收益最多 8 RP。

等级和金币提供进度状态；材质按 0 / 100 / 450 / 1400 击破阶梯推进，只有新补块改变 HP 和金币。阶段切换依赖升级可感的击破次数变化与覆盖范围变化；费用上涨提供选择窗口。
