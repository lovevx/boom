# 数值平衡 v3（2026-10-13）

完整 Demo 改为首轮 + 三次转生后的四轮工程，休闲混合玩家目标 20–30 分钟，中位目标 24–26 分钟。首次伤害升级 ≤20 秒、首炮 45–90 秒；不设置时间锁。阶段时间与引擎验证、真人测试边界见 [Demo_Pacing.md](Demo_Pacing.md)。

本文为当前代码的有效参数。旧版统一 `2 × 1.3^等级`、基础金币每级 +5、30 万金币得 1 RP 的方案已替换。

## 目标与取舍

保留从 1 点锤击伤害开始、击破才掉金币、逐渐转向自动轰炸的核心循环。首级锤伤仍为 2 金币，继续承接已有教程；后续费用按分支独立定价，让“更快击破”“扩大覆盖”“增加收入”形成选择。阶段用金币与击破数驱动，不用强制时间锁。

首台炮台应在建立点击循环后出现；有效首转给 2 RP，够购买两个根节点，或同方向的根节点与一个低价子节点。自动锤需先购买基础伤害，再花 2 RP，通常承接第二次转生。

| 金币倍率 | 1.0 / 1.25 / 1.5 / 1.75 / 2.0 / 2.25 | 45 / 240 / 850 / 2600 / 7500 |
| 基础金币 | 0 / 1 / 2 / 3 / 4 / 5 | 60 / 300 / 1100 / 3400 / 9500 |
| 下落速度 | 1.0 / 1.25 / 1.5 / 1.8 | 25 / 180 / 700 |
| 炮台数量 | 0 / 1 / 2 / 3 / 4 | 40 / 900 / 4500 / 15000 |
| 发射速率 | 1.0 / 0.85 / 0.72 / 0.6 | 200 / 1100 / 4200 |
| 炸弹伤害 | 10 / 14 / 19 / 25 / 34 / 46 | 80 / 450 / 1600 / 5200 / 16000 |
| 炸弹范围 | 70.0 / 95.0 / 120.0 / 145.0 / 170.0 / 200.0 | 100 / 500 / 2300 / 7500 / 24000 |

数值列是累计效果而非每级增量。倍率属性实际值 = 单局表值 ×（1 + 永久百分比）。锤伤只作用于锤子；炮台伤害独立计算，避免买锤伤同时强化炮台而压过其他路线。炮台数量不再同时缩短冷却，各数量等级基础间隔统一 3.4 秒，速率满级为 2.04 秒。

锤击间隔 = max(0.30, 0.5 / 实际攻速倍率)。锤击范围 0 表示点查询；范围大于 0 时为圆形与方块碰撞形状相交，半径 12 提高边缘点击容错，24 起能稳定碰到相邻方块。

炮台伤害 =（单局伤害表 + 永久炮台基础伤害）×（1 + 弹药强化）。爆炸距离衰减为 clamp(1 - 距离 / 半径, 0.3, 1.0)。查询上限从默认 32 调为 512，覆盖完整 360 块建筑；射击动画跟随冷却缩短，避免速率升级被动画长度抵消。

## 机制升级

| 内容 | 累计转生门槛 | 前置 | 效果 Lv.0 → Lv.3 | 费用 |
| --- | --- | --- | --- | --- |
| 暴击率 | 1 次 | 锤伤 Lv.2 | 0 / 10% / 20% / 30% | 250 / 1000 / 3200 |
| 暴击伤害 | 1 次 | 暴击率 Lv.1 | ×2 / ×2.5 / ×3 / ×3.5 | 400 / 1600 / 4800 |
| 连锁伤害 | 2 次 | 炮弹伤害 Lv.2 | 0 / 15% / 30% / 45% | 400 / 2600 / 8000 |
| 散射炮 | 3 次 | 炮弹范围 Lv.1 | 1 / 2 / 3 / 4 发 | 200 / 7000 / 22000 |

暴击为锤击机制，初始倍率 ×2，因此先购买暴击率立即有增伤；连锁只追加一次邻近伤害，散射增强覆盖且仍共用同一台炮的发射周期。

## 转生收益

首次、第二次、第三次转生最低产出分别为 4000 / 9000 / 30000；后续转生沿用 30000。门槛由 `ReincarnationManager.run_gold_targets` 统一提供，低于当轮门槛不能转生；达到门槛后，RP = min(8, floor(sqrt(本局拆楼产出 / 1000)))。下表表示满足当轮门槛后的数学收益；例如第三轮产出 25000 仍不能转生。

第三次转生后的最终工程目标为本轮产出 1000000，且实际发射至少 10 轮散射。散射在范围 Lv.1 即可购买一级；早期多发加速收入后，用最终目标保留组合展示空间。工程进度与下一档 RP 分开显示，达到 RP 上限不等于完成工程。提前再次转生会清空本轮工程进度，确认窗明确提示。

| 本局拆楼产出 | RP |
| --- | --- |
| 3999 | 0，未达门槛 |
| 4000 | 2 |
| 9000 | 3 |
| 16000 | 4 |
| 25000 | 5 |
| 36000 | 6 |
| 49000 | 7 |
| 64000 及以上 | 8，单局上限 |

收益按产出累计，花掉金币不影响 RP；开局资金只记余额，不记 RP 产出或生涯收入。零收益结算不会增加转生次数。单局 RP 上限防止一局囤出全部永久节点，玩家有继续转生与解锁机制的目标。

## 验证与估算边界

**以下 2026-10-09 模拟与记录为历史基线，不代表 v3 时长。** 当前版本使用覆盖全部成长机制的 `tools/demo_pacing_simulate.py` 和真实引擎驱动 `tools/demo_pacing_run.gd`，当前报告见 `artifacts/demo-pacing/` 与 [Demo_Pacing.md](Demo_Pacing.md)。功能检查不能替代首次玩家试玩。

2026-10-09 Demo 扩展：新增 10 个单局节点与 9 个永久专精，参数见 [Demo_Expansion.md](Demo_Expansion.md)，代码目录为 `UpgradeManager.DEMO_NODES` 与 `ReincarnationManager.NODE_DEFS`。基础转生公式保留。下方 24 场模拟结果针对扩展前版本，不包含连击、合同、回收、余震、重炮与折扣，不能代表新增内容的实际时长。

`tools/balance_verify.gd` 在独立 `BoomameBalanceValidation` 用户目录验证购买扣款、前置、满级、RP 边界、加成乘算、存读档、独立槽位、自动锤、实际炮台间隔、爆炸覆盖和面板状态。结果在 `artifacts/balance/verification.json`。

`tools/balance_simulate.py` 直接读取生产升级表与材质表，使用三组种子、边缘/内部爆炸、继续手动/解锁后挂机、首局/第二局，共 24 个模型场景，每场模拟 30 分钟。第二局投入金币之心 Lv.1 与基础伤害 Lv.1。

当前模型：首炮 82～83 秒；首转主动拆楼 259～285 秒（约 4.3～4.8 分钟），解锁后挂机 402～509 秒（约 6.7～8.5 分钟）。第二局首转主动 136～152 秒、挂机 272～369 秒。模型忽略弹道耗时、空炮、塌落补块等待、菜单购买时间与操作失误，是估算，不能当真人试玩通过。30 分钟输出也是模型上界，RP 已由单局 8 点封顶。

真人复测：记录首级伤害、首炮、第一次/第二次转生的时间；检查是否有人只选金币分支，范围是否比伤害划算，以及转生是否让同等操作更快。若首炮超过 3 分钟，先降低首炮费用；若首转超过 15 分钟，优先检查炮弹命中与补层速度，再调收益门槛。若首转少于 3 分钟，先提高中段费用，再提高门槛。功能检查通过不代表手感或真人节奏已验收。
