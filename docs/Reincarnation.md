# 转生与永久技能树（2026-10-09）

数值参数以 [Numeric_Balance.md](Numeric_Balance.md) 和 `ReincarnationManager` 为准。

Demo 扩展已新增 9 个永久专精节点，永久树共 21 个节点；首三次转生也开放重锤、重炮、余震、空中解体等单局机制。详细效果、RP 费用与前置见 [Demo_Expansion.md](Demo_Expansion.md)。本页下方 12 个节点为保留的基础树；次数型解锁表同样保留，新增内容叠加在原有解锁之上。

## 结算规则

首次 / 第二次 / 第三次及后续转生，分别要求本轮拆楼产出 ≥4000 / 9000 / 30000。达到当前门槛后，RP = min(8, floor(sqrt(产出 / 1000)))，前三次门槛结算分别为 2 / 3 / 5 RP。已消费金币仍计入产出，初始资金不计入。转生清空本轮金币、击破数、升级和散射发射次数，保留 RP、永久节点、累计试玩用时与有效转生次数。0 RP 结算被管理器拒绝，不会获得次数型解锁。

完整 Demo 以三次转生后的最终工程完成为收尾，目标与计时规则见 [Demo_Pacing.md](Demo_Pacing.md)。最终工程未完成时再次转生，二次确认窗提示进度损失；Demo 完成后可以继续游玩。

面板暂停游戏，显示本次 RP、下一档还差多少金币、下次次数解锁；达到 8 RP 后显示本局上限。二次确认框显示清空内容、永久保留节点和本次解锁。未达门槛的按钮禁用。

## 次数型解锁

| 有效转生次数 | 新内容 |
| --- | --- |
| 1 | 暴击升级；开局自带 1 台炮台 |
| 2 | 连锁升级 |
| 3 | 散射升级；开局自带 2 台炮台 |
| 5 | 开局自带 3 台炮台 |
| 8 | 开局自带 4 台炮台 |

首局仍能用金币购买 1～4 台炮台。永久解锁提供开局数量，单局数量升级只购买余下的炮台，不重复加台。

## 存档

沿用 `SaveManager` 三槽位 ConfigFile 格式和所有节点 ID。读取顺序：恢复 meta → 重置单局 → 重算永久加成（不发资金）→ 恢复单局等级 → 覆盖金币。新建空槽位清空 meta，防止另一个槽位的永久技能串档。既有存档保留等级与余额，后续效果和费用使用新版本参数。
