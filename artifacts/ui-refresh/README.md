所有运行使用独立项目副本与 `BoomameDemoValidation` 用户数据目录，没有覆盖玩家存档。导出包在空目录中验证，排除了开发目录的资源回退；新炮、图标、楼体生成和 UI 接口均正常，旧炮及创作源图不在包内。`validation.pck` 使用隔离应用名称，仅作验包证据，并非正式发行构建。

最终 UI、坍塌与验包运行没有 `SCRIPT ERROR`。Godot 测试退出时仍有 CanvasItem/ObjectDB 及部分套件的资源在用提示，未将这些提示计为零警告；本轮未进行长时间内存稳定性验证。

快速切换场景时落地尘土的延迟回调曾捕获已释放场景，已改用弱引用并通过坍塌复测。
